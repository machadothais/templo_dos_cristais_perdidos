# Templo dos Cristais Perdidos

Projeto desenvolvido em linguagem C para a disciplina de **Lógica de Programação e Algoritmos**, da Pós-Graduação em **Desenvolvimento de Sistemas Web e Aplicativos Móveis**.

## Sobre o projeto

O projeto consiste no desenvolvimento de um programa com dinâmica de jogo, utilizando conceitos básicos de lógica de programação.

O jogo criado se chama **Templo dos Cristais Perdidos**. Nele, o jogador precisa explorar um templo, coletar cristais, encontrar chaves e evitar armadilhas para conseguir vencer a aventura.

## Objetivo do jogo

O objetivo do jogo é chegar ao final da exploração com energia suficiente, coletando cristais e tomando decisões durante as rodadas.

## Como funciona

* O jogador inicia com uma quantidade de energia.
* A cada rodada, escolhe uma ação.
* Eventos aleatórios acontecem durante o jogo.
* O jogador pode ganhar ou perder energia.
* O jogo termina quando o jogador vence a aventura ou perde toda a energia.

## Conceitos utilizados

* Linguagem C
* Estruturas sequenciais
* Estruturas condicionais
* Estruturas de repetição `for` e `while`
* Randomização com `rand()` e `srand(time(NULL))`
* Interação com o usuário pelo terminal

## Restrições da atividade

O projeto foi desenvolvido sem o uso de:

* Vetores
* Matrizes
* Funções
* Procedimentos
